# Library Management System

A Python-based console application for managing a small library's books, members, borrowing operations, reservations, and return history.

## Features

- Add and manage books
- Register and manage members
- Issue and return books
- Handle unavailable books using a reservation waitlist
- Track recently returned books
- Search books by ISBN
- Search books by title
- Persistent data storage using JSON

## Data Structures & Algorithms

This project demonstrates practical implementation of:

- **Queue (FIFO)** — reservation waitlist
- **Stack (LIFO)** — recently returned book history
- **Binary Search** — searching books by ISBN
- **Linear Search** — title-based book search

## Technologies Used

- Python
- JSON
- Data Structures & Algorithms
- File Handling
